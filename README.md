# Pashu Aahar
​
 **Pashu Aahar** is a smart, offline-first Android application designed to help farmers optimize cattle nutrition. By calculating precise feed recipes based on breed genetics and milk yield, the app helps improve cattle health and maximizes farmer profits through significant cost savings.
​
 ## Features
​
** Multi-lingual Interface**: Supports English, Hindi (हिंदी), and Marathi (मराठी) to ensure accessibility for local farmers.
** Scientific Nutrition Calculator**: 
     - Customized feed plans based on Breed (Desi, Jersey, Holstein).
     - Precise measurements for Maize (Energy), Oil Cake (Protein), and Roughage (Fiber).
** Cost Savings Tracker**: Compares the cost of homemade balanced feed vs. expensive market feed, showing daily and monthly savings.
** Veterinary Knowledge Base**: Essential tips on cattle hygiene, grain storage, and watering schedules.
** 100% Offline**: No internet  required after installation. All formulas and data are stored locally.
** Modern UI/UX**: Built with Jetpack Compose and Material 3, featuring smooth animations and an intuitive "Farmer-First" design.
​
 ##  Tech Stack
​
**Language**: Kotlin
**UI Framework**: Jetpack Compose
**Design System**: Material 3
**Navigation**: Navigation Compose
**Build System**: Gradle (Kotlin DSL) with Version Catalogs
​
 ##  Installation
​ 1. Clone the repository or download the source code.
 2. Open the project in **Android Studio (Ladybug or newer)**.
 3. Ensure you have **Android SDK 35** installed.
 4. Sync Gradle and click the **Run** button.
​
 ##  User Flow

 1. **Home Screen**: Select language and navigate to Cow Profile or Tips.
 2. **Cow Profile**: Input breed, weight, age, and current milk yield using intuitive sliders and chips.
 3. **Result Screen**: View the customized daily recipe and see how much money you save compared to market feed.
 4. **Knowledge Base**: Read scientific tips to maintain cattle health and improve yield.
