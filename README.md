# Pashu-Aahar (Cattle Nutrition Calculator)

Pashu-Aahar is a mobile application developed in Kotlin using Jetpack Compose. It is designed to assist small-scale dairy farmers in generating balanced and cost-effective feed recipes for their cattle using locally available ingredients.

## 🚀 Features

- **Cow Profile Management**: Input breed (Desi, Jersey, Holstein), weight, age, and milk yield.
- **Smart Nutrition Logic**: Calculates feed requirements (Maize, Oil Cake, Roughage) based on scientific cattle nutrition standards.
- **Multi-lingual Support**: Supports **English, Hindi, and Marathi** for better accessibility in rural areas.
- **Cost Savings Tracker**: Compares the cost of homemade feed with market alternatives and calculates monthly savings.
- **Veterinary Knowledge Base**: Provides essential tips on hygiene, storage, and watering.
- **Offline Functionality**: Works 100% without an internet connection after installation.

## 🛠 Tech Stack

- **Language**: Kotlin
- **UI Framework**: Jetpack Compose (Material 3)
- **Navigation**: Jetpack Navigation Compose
- **Architecture**: Modern Android Architecture

## 📱 How to Use

1. **Home Screen**: Select "Start Calculation" or browse tips.
2. **Language**: Use the globe icon in the top right to switch between English, Hindi, and Marathi.
3. **Data Entry**: Select the breed, adjust the milk yield slider, and enter the cow's weight.
4. **Results**: View the exact recipe mix and see how much you save daily and monthly.
5. **Knowledge Base**: Read through essential veterinary tips for better cattle health.

## 🔨 Installation

1. Clone the repository.
2. Open the project in **Android Studio (Ladybug or newer)**.
3. Sync Gradle and run the app on an emulator or a physical device.
